Reader defaults means resolving a page’s final filter values by combining defaults for its page type with explicit page settings and removing empty selections.

A reader filter is a page attribute, such as audience or product, used to narrow the documentation shown to a reader.

These 80 cases test `pageReaderFilters`: 40 development cases used to check the evaluation’s prompts and runner settings, and 40 test cases reserved until those choices were fixed. Neither set trains the models. The supplied source code is the rule; expected answers come from executing it.

**Question type: `choice` (four options).** The model selects the exact returned result or error, with a probability for each option.

**Exact question:** Which exact result or exception does pageReaderFilters produce for these arguments?

[Source at the recorded revision](https://github.com/shoalrun/shoalrun/blob/1f2ed786f11d3510182c10184693c23f04a2ae35/framework/src/reader-filters.ts). See [methodology](doc:guide.methodology), [the case-set overview](doc:reference.expanded-cases), and [results](doc:report.2026-10-30).
