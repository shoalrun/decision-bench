Each report records a comparison against fixed questions with known answers. Reports retain the exact model versions, dataset, settings, and results so comparisons remain understandable as the model catalog grows.

Development cases check the evaluation’s prompts and runner settings; held-out test cases measure performance after those choices are fixed. Neither set trains the models.
